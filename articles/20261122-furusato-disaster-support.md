# 各自治体の状況

## 1. 輪島市: 被害規模、二重被災、未完了の復旧がすべて重なる

- **被害**: 地震による住家被害は全壊2,311棟、半壊3,971棟、一部損壊4,352棟
- **復旧の進み具合**: 市が被害集計を終えた2025年9月時点で、公費解体は受理12,465棟のうち10,923棟（87.6％）が完了、上水道の復旧率は97.3％
- **2026年の状況**: 8月時点でも災害公営住宅の設計と事業者選定が続いている。11月時点でも市の公式サイトは「大規模災害時モード」で運用され、住宅、公費解体、事業者支援、給水、医療の情報を災害情報として掲載している
- **寄附の使途**: 災害支援ふるさと納税は返礼品なしで、寄附金はすべて復旧・復興事業と今後の防災対策事業に使うと市が明記している。返礼品付きの通常寄附も再開しているが、再開できていない事業者もある

寄附ページ: https://www.city.wajima.ishikawa.jp/article/2024010700079/

## 2. 珠洲市: 恒久住宅への移行に数年かかる

- **住宅復興の時間軸**: 2026年9月時点の復興公営住宅の計画では、2027年度完成の団地に加え、鵜飼団地（60戸）と野々江町団地（50戸）が2028年度、飯田地区の一部が2029年度の完成予定
- **意味すること**: 多くの被災世帯にとって、仮住まいから恒久住宅への移行が2026年中には終わらない
- **寄附の使途**: 2026年1月に、返礼品なしの災害支援寄附を継続すると発表している。返礼品付きの通常寄附も再開しているため、申込画面で「能登半島地震災害支援」の窓口であることを確かめる必要がある

## 3. 能登町: 未完了の復旧が完成年月まで公開されている

# 返礼品なしの寄附と返礼品付きの寄附

2つは目的が異なるので、分けて考えます。

| | 災害支援型（返礼品なし） | 通常型（返礼品付き） |
|---|---|---|
| 主な受け手 | 自治体の復旧・復興事業 | 自治体の財源と、返礼品を出す地元事業者 |
| 利点 | 返礼品の調達費がかからず、寄附額の多くが自治体の財源になる | 被災した農業・水産業・伝統産業の売上を支えられる |
| 向いている人 | 復興事業そのものに資金を届けたい人 | 地域の事業者の再建も支えたい人 |

輪島市と珠洲市は返礼品の受付を部分的に再開しており、能登町では通常寄附でも復旧・復興を使途に指定できます。たとえば、寄附予算の一部を返礼品なしの災害支援寄附に、残りを被災地の産品を選ぶ通常寄附に振り分ける方法も合理的です。

# 2026年の制度と控除の注意点

- **控除の仕組み**: 総務大臣の指定を受けた自治体への寄附は、自己負担2,000円を除いた額が所得税と住民税から控除される。上限は所得、扶養、各種控除で決まり、住民税の特例控除には所得割額の20％という上限がある
- **ワンストップ特例**: 確定申告の不要な給与所得者などは、年間の寄附先が5自治体以内なら利用できる。医療費控除などで確定申告をすると特例は無効になり、すべてのふるさと納税を確定申告に含める必要がある
- **返礼品なしでも控除対象**: 地方公共団体の災害対策本部などへの寄附は、原則として寄附金控除の対象になり、住民税上もふるさと納税として扱われうる。ただし日本赤十字社などを通じた義援金は、証明書類や税務上の確認方法が異なる場合がある
- **ポイント付与の禁止**: 2025年10月以降、ポータルサイトが寄附者に独自ポイントを付けて募集することは禁止された。2026年は、ポイント還元率で寄附先を選ぶ制度環境ではない
